# **Nexora Ensuite**

## Repository Structure

```
backend/      - API logic and service modules
database/     - SQL schema, rules, logic, migrations
frontend/     - Web application scaffold
scripts/      - Docker, Supabase and automation scripts
services/     - Worker services and integrations
tests/        - Test harness
```

## Developer Setup

1. Clone the repository
2. Install dependencies as required per folder
3. Start PostgreSQL (local or Docker)
4. Run database migrations in order
5. Start backend
6. Start frontend
